# 4-bit ALU Design using Verilog HDL

## Description
Designed a 4-bit Arithmetic Logic Unit (ALU) supporting multiple arithmetic and logical operations using Verilog HDL and simulated using Xilinx Vivado.

## Operations implemented
Addition
Subtraction
AND
OR
XOR
NOT
Shift Left
Shift Right

## Tools Used
Verilog HDL
Xilinx Vivado Simulator

Simulation waveform attached in repository
